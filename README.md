# ZenBox

Web estática (sin servidor ni IA) que muestra el estado de tu Gmail y tu agenda de Google Calendar.
Todo se procesa en el navegador con permisos de solo lectura.

- `config.js`: pon aquí el ID de cliente OAuth de Google. Vacío = modo demostración.
- `app.js`: conexión con Google, clasificación por reglas y pantalla.
- `privacidad.html`: política de privacidad (necesaria para la verificación de Google).

Se publica con GitHub Pages desde la rama `main`, carpeta raíz.
